# Test Cases

  Регистрация

TC-REG-001

Название: Успешная регистрация с валидными данными
Тип: Функциональный

Предусловия: Открыта страница регистрации

Шаги:
1. Ввести корректный email ([test@mail.com](mailto:test@mail.com))
2. Ввести пароль (не менее 8 символов)
3. Подтвердить пароль
4. Нажать "Зарегистрироваться"

Ожидаемый результат:
Пользователь успешно зарегистрирован, происходит переход в личный кабинет

TC-REG-002

Название: Регистрация с пустыми полями
Тип: Функциональный

Шаги:
1. Оставить все поля пустыми
2. Нажать "Зарегистрироваться"

Ожидаемый результат:
Отображаются сообщения о необходимости заполнения обязательных полей

TC-REG-003

Название: Регистрация с некорректным email
Тип: Функциональный

Шаги:
1. Ввести email: test@
2. Ввести валидный пароль
3. Нажать "Зарегистрироваться"

Ожидаемый результат:
Появляется ошибка валидации email

TC-REG-004

Название: Время отклика формы регистрации
Тип: Нефункциональный (Performance)

Шаги:
1. Заполнить форму валидными данными
2. Нажать "Зарегистрироваться"

Ожидаемый результат:
Время отклика системы не превышает 2 секунд



  Поиск

TC-SRCH-001

Название: Успешный поиск по валидному запросу
Тип: Функциональный

Шаги:
1. Ввести в поле поиска "телефон"
2. Нажать Enter

Ожидаемый результат:
Отображается список релевантных товаров

TC-SRCH-002

Название: Поиск с пустым полем
Тип: Функциональный

Шаги:
1. Оставить поле поиска пустым
2. Нажать Enter

Ожидаемый результат:
Отображается сообщение или ничего не происходит (в зависимости от требований)

TC-SRCH-003

Название: Поиск с некорректным вводом
Тип: Функциональный

Шаги:
1. Ввести "!!!@@@"
2. Нажать Enter

Ожидаемый результат:
Отображается сообщение "Ничего не найдено"

TC-SRCH-004

Название: Производительность поиска
Тип: Нефункциональный (Performance)

Шаги:
1. Ввести любой запрос
2. Нажать Enter

Ожидаемый результат:
Результаты поиска отображаются не более чем за 2 секунды




  Корзина

TC-CART-001

Название: Добавление товара в корзину
Тип: Функциональный

Предусловия: Открыта страница товара

Шаги:
1. Нажать "Добавить в корзину"

Ожидаемый результат:
Товар добавлен в корзину

TC-CART-002

Название: Проверка минимального количества товара
Тип: Функциональный

Шаги:
1. Установить количество товара = 0
2. Попробовать добавить в корзину

Ожидаемый результат:
Система не позволяет добавить товар, отображается ошибка

TC-CART-003

Название: Проверка максимального количества товара
Тип: Функциональный

Шаги:
1. Установить количество товара больше допустимого (например, 1000)
2. Добавить в корзину

Ожидаемый результат:
Система ограничивает количество или выводит сообщение об ошибке

TC-CART-004

Название: Сохранение корзины после перезагрузки страницы
Тип: Функциональный

Шаги:
1. Добавить товар в корзину
2. Обновить страницу

Ожидаемый результат:
Товар остается в корзине

TC-CART-005

Название: Время обновления корзины
Тип: Нефункциональный (Performance)

Шаги:
1. Добавить товар в корзину

Ожидаемый результат:
Корзина обновляется не более чем за 2 секунды

TC-CART-006

Название: Удобство отображения корзины
Тип: Нефункциональный (Usability)

Шаги:
1. Открыть корзину

Ожидаемый результат:
Информация о товарах отображается корректно и читаемо
